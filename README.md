# Wish list

A small family wish list page. People pick their name, then mark what they plan to give so nothing gets bought twice. No accounts.

- `index.html`, `app.js`: the page
- `firebase-config.js`: public Firebase web config (project `roman-wish-list`)
- `firestore.rules`: who can read and write what

Deploy the page with `git push` (GitHub Pages serves `main`). Deploy rules with `firebase deploy --only firestore --project roman-wish-list`.
